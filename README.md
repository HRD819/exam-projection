# 考試智慧投影系統｜GitHub Pages + Google Sheets CSV

靜態 HTML／CSS／JavaScript 投影頁直接讀取 Google Sheets 發布到網路的 CSV；不使用 Google Apps Script 作為網站、API 或後端，也不包含 Google／Dropbox 金鑰。五階段、手動控制、下一階段及恢復自動均保留。

## 重要：公開範圍

依教師選擇，直接發布原試算表，並非發布去識別副本。**已發布的所有工作表與欄位將供網路讀取，包含排程、K「備註」、L「檢查結果」、課程對照、系統設定中的 Dropbox 資料夾網址、O/P 座位表連結以及 00_note。** 公開讀取和 Google Sheets 編輯權限是兩件事：原有的兩個編輯帳號不因發布而改變。請勿把不希望公開的資訊放入已發布範圍。Google 發布可能延遲數分鐘，網站每 60 秒重新讀取不代表發布端即時更新。

## 教師設定：一次發布、一個網址

1. 開啟既有的五張工作表，確認準備公開的內容，再於「檔案 → 共用 → 發布到網路」選**整份文件**並發布。這是 Google 官方的公開操作，與「知道連結的人可編輯」不同；不要修改原有兩位編輯者。
2. 複製 Google 產生的發布網址，通常以 `https://docs.google.com/spreadsheets/d/e/2PACX-.../pubhtml` 開頭。**不要貼原始的 `/edit` 網址，也不要貼私人憑證。**
3. 目前已將教師提供的發布網址寫入網站設定；打開網站即可嘗試讀取。日後更換發布網址時，在右下角「教師控制」展開「設定 Google Sheets 公開 CSV」，貼上新發布網址並按「帶入工作表」，再按「儲存並同步」。程式依本試算表固定的 gid 101–104，自動構造四張表的 CSV 網址。
4. 資料讀取成功後按「複製含設定的投影網址」，把它交給助教。此網址包含公開發布網址，任何取得者都能讀取已發布資料。若 CSV 已發布但無法讀取，先檢查 Google 的發布範圍、組織政策及瀏覽器跨來源限制。
5. 未設定或首次讀取失敗時，只顯示目前時間，教師控制列顯示錯誤。同步成功後將資料（含公開 PDF 連結）緩存在該瀏覽器的 localStorage；斷線可讀取上次快取並顯示最後成功時間與失敗狀態。不同電腦各自快取；首次離線不能讀取新資料。

## 資料管理：哪些功能沒有 Apps Script

| 功能 | 純 CSV 版的做法 |
|---|---|
| 原本五張工作表與欄位 | 保留；`01_考試清單` 新增 O、P 兩個 PDF 連結欄。 |
| 課程、考試類型、版本下拉與核取方塊 | 使用 Google Sheets 原生資料驗證。H、I、N 版本下拉直接參照版本表的 A 欄，新增版本會跟隨範圍；同一版本多列可能在選單重複顯示。 |
| 固定且不重複的考試 ID | **教師手動填寫** `E0001` 等，且自行記錄已使用編號、刪除後不重用。網頁會警告缺漏、格式錯誤或重複並排除無效排程；純 CSV 不能自動配號或保證被刪除的編號永不重用。 |
| 考前提醒 H 的初次預設帶入 | 教師參照 M/N 課程對照，**手動選擇 H 欄**；之後修改對照不會自動回寫既有考試。I 欄注意事項版本也自行指定。 |
| L「檢查結果」 | 純 CSV 網站**無法寫回 L 欄**。請在網站的「教師控制 → 資料檢查」查看即時計算的警告；L 欄既有 Apps Script 結果可能過期，保留供參考。 |
| 原先安裝的 Apps Script 觸發器 | 此版本不依賴它們。如果先前已安裝且想完全停止自動改寫，請在 Apps Script 左側「觸發條件」中自行檢查並停用／刪除舊觸發器；不要刪除未辨識或其他專案的觸發器。 |

正確日期為真正日期值（顯示 `yy/mm/dd`，例如 `26/11/06`）或明確的 `yyyy/mm/dd`；開始／結束時間為 24 小時制 `HH:mm`。不合法資料、無 ID、重複 ID 不會自動選場。多場重疊時保持等待並警告。

## 座位表 PDF

在 `01_考試清單` 的 O、P 填寫最多兩個可供任何網址持有人讀取的 HTTPS **直接 PDF** 連結；兩欄均空白時顯示「請參閱現場紙本座位表」。一份多頁同時顯示全部頁面；兩份各顯示第一頁。每份上限 12 MB，單份最多 12 頁，超限不省略頁面而改用紙本。頁數過多時應先確認投影可讀性。

瀏覽器必須能跨來源讀取 PDF（CORS）；Dropbox 或其他服務的分享預覽網址不一定可用。此版不使用 Dropbox API、金鑰或中介伺服器。若連結要求登入、不是 PDF、超限、網路失敗或服務沒有允許跨來源，會顯示紙本提示及教師控制列錯誤；不能把失敗視為確定沒有 PDF。請用實際分享連結和教室瀏覽器事前驗收。檔名若符合 `YYMMDD_科目_教室.pdf`，會擷取教室名稱；否則顯示「座位表 1／2」。

## 時間與部署

網站以設備時間換算台灣時區，每秒以絕對時間判定階段，正式考試不顯示倒數。純靜態網站不提供可信伺服器校時；控制列標示「時間未校正」，請先確認 Windows 自動校時。

本機預覽：在原專案資料夾雙擊 `啟動預覽.cmd`，或 `npm run build` 後執行 `npm start`。開發模擬網址 `http://127.0.0.1:4173/?demo=1` 清楚標為非正式投影。GitHub Pages 使用 `.github/workflows/pages.yml` 部署 `dist/`；`npm run ci` 執行核心與 CSV 測試並建置。
